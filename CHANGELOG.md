# История версий AngelTime (кратко)

- **v0.4.22 — No Blue Selection**: без синего выделения WebView2; выделение редактируемого текста и фокус сохранены.
- **v0.4.21 — Unified Design**: единство чёрно-золотого интерфейса четырёх вкладок.
- **v0.4.20 — Smooth Timer Bar**: плавная полоса обратного отсчёта, плавность между обновлениями Rust.
- **v0.4.19 — Calm Stopwatch**: меньше визуальных обновлений сотых при сохранении точного времени.
- **v0.4.18 — Smooth Numbers / No Laps**: плавность чисел, удаление кругов секундомера.
- **v0.4.17 — Premium Tabs**: переработаны таймер, секундомер и настройки.
- **v0.4.16 — Final UI Polish**: завершающая полировка списка будильников.
