# AngelTime v0.4.28 — публикация на GitHub

- Репозиторий: `TraurigerEngel/AngelTime`.
- Ветка: `main`.
- Git-тег и GitHub Release: `v0.4.28`.
- **Не перезаписывать** исторический тег/релиз `v0.4.22`.

В комплекте для публикации находится скрипт `PUBLISH-RELEASE-v0.4.28.ps1` и отдельный архив исходников. Скрипт проверяет GitHub CLI, Git, версию, контрольные суммы ZIP и локального EXE, клонирует репозиторий в **новую временную папку**, копирует исходники и публикует новый тег. После этого создаёт GitHub Release с Portable EXE, исходниками и SHA-256.

**Запуск из корня распакованного релизного комплекта:**

```powershell
& powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\PUBLISH-RELEASE-v0.4.28.ps1
```

Исполняемый файл берётся из `T:\Downloads\Projjj\AngelTime_v0.4.23_Dev\dist\AngelTime_v0.4.28_Portable.exe`; исходный проект не изменяется. При необходимости передайте параметр `-ProjectPath`.

Скрипт запрашивает подтверждение перед публикацией и никогда не выполняет `git push --force`. Репозиторий на момент подготовки публичный: проверьте права на встроенный MP3 перед подтверждением.
