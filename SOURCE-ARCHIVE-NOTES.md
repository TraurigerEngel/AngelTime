# AngelTime v0.4.28 — происхождение исходного архива

Исходный архив v0.4.28 восстановлен из `AngelTime_v0.4.22_Source.zip` (SHA-256 `7CF6F172225433BF9217FE0AD2D4291C70AE53A119601FB70A745B7F3A25AAFA`) последовательным применением **шести патчей** версий 0.4.23–0.4.28.

Для каждого патча были сравнены все `BASELINE-SHA256.txt` с предыдущей версией и все `PAYLOAD-SHA256.txt` с помещаемыми файлами. Все сравнения прошли успешно.

Документация (`README.md`, `RELEASE_NOTES.md`, `GITHUB-RELEASE-GUIDE.md`, этот файл) обновлена под публикацию v0.4.28. `SHA256SUMS.txt` пересчитан для всего исходного комплекта. Устаревший издательский скрипт, рассчитанный на выпуск 0.4.22, не входит в новый исходный архив.

**Сборка Windows EXE выполнена владельцем локально.** В подготовленной среде Windows/Tauri исполняемый файл не собирался; релизный скрипт проверяет точную контрольную сумму существующего EXE перед публикацией.

В исходниках присутствует аудиозапись `src-tauri/resources/default_alarm.mp3`, право на распространение которой требует самостоятельной проверки.
