# AngelTime v0.4.22 — исходники контрольной версии

Снимок исходников собран из рабочей цепочки AngelTime до патча No Blue Selection v0.4.22.

Комплект содержит Tauri 2/Rust, интерфейс, JS-тесты, ресурсы и Windows-скрипты сборки.

В составе **нет** бинарного Windows EXE, node_modules, Cargo target, локальных пользовательских настроек, резервных копий и кэшей. Оригинальная установленная версия на ПК пользователя непосредственно не считывалась; архив построен из исходников/патчей, доступных в диалоге.

Обновлены: документы версии, сборочная упаковка для v0.4.22, SHA-256 манифест. Основной код приложения не менялся.
