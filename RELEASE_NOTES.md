# AngelTime v0.4.22 — Unified Design / No Blue Selection

Контрольный выпуск интерфейса AngelTime для Windows 11.

### Основные изменения с v0.4.16

- Единый чёрно-золотой стиль будильников, таймера, секундомера и настроек.
- Удалены круги секундомера и декоративная нумерация вкладок.
- Мягкая анимация цифровых табло с учётом настройки «Меньше анимаций».
- Работающий секундомер отображает десятые спокойнее, а при паузе сохраняет точность до сотых.
- Плавная анимация полосы прогресса основного таймера без округления до целых процентов.
- Убрано синее выделение текста WebView2, сохранена возможность выделять текст в полях ввода и золотой контур фокуса.

### Совместимость

- Windows 11 x64; Tauri 2, Rust.
- Данные будильников и пользовательские настройки сохраняются.

### Тестирование

- JavaScript: 39/39 тестов на этом снимке исходников.
- Последняя подтверждённая по журналу Windows Release-сборка: v0.4.21.
- Для v0.4.22 требуется локальная сборка и проверка перед публикацией EXE.

### Важно о звуке

В комплекте исходников есть встроенная аудиозапись `default_alarm.mp3` («アリシャ»). По умолчанию выпуск публикуется в **приватный** GitHub-репозиторий, пока права на распространение аудио не подтверждены.
