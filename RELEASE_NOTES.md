# AngelTime v0.4.28 — Two-Column Alarms

**Стабильная контрольная версия для Windows 11.**

## Новое после v0.4.22

- **Две колонки будильников** — до 10 карточек в каждой на большом окне, сохранены высота строк и двухстрочная подача названия и расписания.
- **Умная сортировка** — включённые будильники по ближайшему времени срабатывания, с учётом повторов и перехода через полночь; выключенные — ниже.
- **Следующий будильник** — сдержанная золотая подсветка и подпись со временем до сигнала.
- **Модальное редактирование** — создание, изменение времени, названия, расписания и удаление через отдельное окно.
- **Резервные копии** — экспорт и проверяемый импорт JSON с подтверждением, возможность отменить последний импорт.
- **Доработка компоновки** — более равномерные отступы и адаптация по доступной ширине и высоте.

Сохранены независимые таймеры, плавная полоса обратного отсчёта, секундомер без кругов, уведомления Windows и системный трей.

- Windows Tauri Release/Portable: **PASS** по журналу владельца.
- SHA-256 Portable EXE: `0745078AD948D7DEF77618C7D4DA0A2F8518EE36CBF301D5902E55D4A68B3B83`.
- Пользователь подтвердил внешний вид двухколоночной компоновки.

## Распространение и данные

В `src-tauri/resources/default_alarm.mp3` присутствует встроенный аудиофайл с метаданными «アリシャ». Права на его публичное распространение отдельно не подтверждены; до публикации исходников и EXE необходимо их проверить либо заменить запись на разрешённую.

Настройки пользователя, резервные копии JSON, импортированные MP3 и личные данные не включаются в исходный релиз. SHA-256 подтверждает целостность скачанных файлов, но сам по себе не гарантирует права на распространение контента.
