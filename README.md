# AngelTime v0.4.28 — Two-Column Alarms

**AngelTime** — настольное приложение для Windows 11 на **Tauri 2 + Rust + JavaScript**: будильники, основной и дополнительные таймеры, секундомер и настройки уведомлений.

## Возможности

- Компактный список до 20 будильников в двух колонках на экране 1080p; редактирование времени, названия и расписания в модальном окне, автоматическая сортировка и подсветка ближайшего будильника.
- Независимые таймеры и плавная полоса прогресса основного таймера.
- Секундомер без кругов, с более спокойным обновлением сотых во время работы и точными показаниями на паузе.
- Настройки звука, мелодии, громкости, плавного нарастания и системных уведомлений.
- Единый тёмный интерфейс с золотыми акцентами и без синего выделения WebView2.
- Работа в системном трее, клавиатурные сочетания, сохранение состояния.
- **Экспорт в JSON** будильников и настроек в «Загрузки», предварительная проверка и подтверждение импорта, отмена последнего импорта после перезапуска.

## Системные требования

Windows 11 x64, Microsoft Edge WebView2 Runtime, для разработки — Node.js/npm, Rust/Cargo (MSVC) и системные компоненты сборки Tauri 2. Для сборки на Windows необходимы инструменты MSVC/C++ Build Tools.

## Сборка из исходников

```powershell
npm install
npm run check
cargo test --manifest-path src-tauri/Cargo.toml
.\BUILD-PORTABLE.cmd
```

После успешной сборки исполняемый файл появится в `dist/AngelTime_v0.4.28_Portable.exe` вместе с `.sha256`.

> `BUILD-PORTABLE.cmd` запускает тесты до сборки. Если сборка не завершилась сообщением `PASS`, не распространяйте получившийся EXE.

## Управление

- `Ctrl+1`—`Ctrl+4` — переключение вкладок.
- `N` — создание будильника (в соответствующей вкладке).
- `Пробел` — запуск/пауза таймера или секундомера (когда фокус не находится в поле ввода).
- `F11` — полноэкранный режим, `Esc` — выход из него.
- Удаление будильника через правую кнопку мыши с подтверждением.

## Резервное копирование

Во вкладке «Настройки» открой раздел «Резервная копия». Кнопка «Сохранить копию» создаёт `AngelTime_Backup_YYYY-MM-DD_HH-MM-SS.json` в системной папке «Загрузки». При восстановлении приложение проверяет структуру и значения JSON, показывает число будильников и спрашивает подтверждение. Перед импортом сохраняется отдельная точка отката, доступная через «Отменить последний импорт» даже после перезапуска.

**Состав копии:** будильники, повторения, рабочие дни, параметры звука и уведомлений. **Не включены:** активные таймеры, секундомер, записи MP3, история срабатываний и данные самой программы. При выборе пользовательского MP3 в копии после импорта будет выбрана стандартная мелодия (файл нужно добавить заново). Не делитесь JSON без необходимости: названия будильников могут содержать личные сведения.

## Данные и приватность

Пользовательские будильники, настройки и импортированные звуковые файлы не входят в этот архив исходников. Не публикуйте резервные копии, данные приложения или персональные файлы из рабочей папки.

**Звуковой ресурс:** в исходниках имеется `src-tauri/resources/default_alarm.mp3` с метаданными «アリシャ». Перед любой **публичной** публикацией исходников или собранного EXE убедитесь в наличии прав на распространение этой записи или замените её на лицензируемый вами звук. Репозиторий `TraurigerEngel/AngelTime` на момент подготовки этого пакета **публичный**. Перед публикацией убедитесь, что у вас есть права на распространение звукового файла.

Лицензия на публичное повторное использование исходного кода в этом пакете не указана. Не добавляйте стороннюю лицензию без решения правообладателя.

## Компоновка v0.4.28

При достаточной ширине и высоте окна будильники отображаются **в две колонки, до десяти карточек в каждой**. Каждая карточка сохраняет время, название и расписание на двух строках, переключатель и кнопку «Изменить». Выделение следующего сигнала и сортировка по ближайшему срабатыванию сохранены. При недостатке места используется пагинация, без уменьшения шрифта или высоты карточек.
